Show off what you're working on with your own vibe!

## Features
- **17 icons to pick from**: the original logo, pastel colors and cute stamp icons!
- **Text presets**: classic, cute, spooky, sleepy ᶻᶻ, or write your own!
- **Custom text** with `{project}` to show your file name.
- **Status verb**: Playing, Watching, Listening to, or Competing in (competitive Blender 😭).
- **Shows your current mode**: Sculpting, Weight Painting, Modeling and more!
- **Secret project mode**: hide your file name if you want privacy ♡.
- **Live timer** since you opened Blender.
- **Crash-proof**: closing or restarting Discord won't break Blender.

## Requirements
- Blender 4.2 or newer, tested on 5.2.
- **Discord desktop app** (the browser version can't show Rich Presence!)
- In Discord: Settings → Activity Privacy → **Share your detected activities** turned on.

## Installation
1. Download the latest `.zip` from [Releases](https://github.com/aesu3d/cute-discord-rpc/releases)
2. In Blender: Edit → Preferences → Get Extensions → ⌄ → Install from Disk
3. Enable **Blender RPC**, then wait a few seconds for your status to appear ✨

## How to use
1. Go to Edit → Preferences → Add-ons → **Blender RPC**
2. Pick your icon, status and text
3. Save your .blend file to show its name, or turn off **Show Project Name** to keep it secret
4. Your Discord status updates every 15 seconds
